**investigación: bitmaps**

también investigamos sobre los bitmaps, ya que pueden ser útiles para mostrar imágenes directamente en la pantalla OLED.

un bitmap es una imagen formada por una matriz de píxeles. en una pantalla pequeña, cada píxel puede representarse mediante datos que Arduino interpreta para decidir qué partes de la imagen se muestran.

esto nos permite, por ejemplo, convertir una ilustración en datos que puedan ser mostrados en la OLED y también trabajar con pequeñas animaciones, utilizando diferentes imágenes o cuadros.

¿por qué nos sirve?
+ permite mostrar ilustraciones personalizadas en la pantalla.
+ podemos trabajar imágenes en formato de píxeles.
+ se pueden utilizar varios bitmaps para crear una animación cuadro por cuadro.
+ es una posibilidad para complementar el código y no depender solamente de texto.
