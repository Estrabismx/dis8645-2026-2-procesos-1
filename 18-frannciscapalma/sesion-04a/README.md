# sesion-04a

## apuntes sesión

Esta clase fue de avanzar con nuestro Proyecto 01, ya tenemiamos de base un código que hicimos días antes juntándonos en la biblioteca usando el arduino uno r4 wifi y la pantalla LCD Oled 0,91" I2C. 

Al principio queríamos cambiar a la raspi y además cambiar la pantalla por una más grande, luego nos dimos cuenta de que habia muy poco registro de uso de la raspi con la Pantalla OLED 1.3" I2C 128x64, controlador SH1106. Para no usar tanta IA y no dificultarnos tanto el encargo (más de lo que ya lo estamos haciendo) decidimos quedarnos con el arduino y usar la pantalla mas grande porque tiene una forma mas similar a una pantalla de televisor, que es lo que estbamos buscando.

En ese momento no teníamos la pantalla y la íbamos a comprar hasta que el Santi consiguió que nos prestaran una, luego el Nico fue modificando el código que ya teníamos para hacer que funcionara en la nueva pantalla, adjunto videos:
