>[!IMPORTANT]
> Al definir una variable, ya sea `int`, `char`, `float`, `bool`, etc. Definimos el contenedor a utilizar, es decir, que asignamos un espacio de la memoria
>
> Esto con el fin de optimizar y no ocupar una bolsa de basura XL para llevar un lápiz 

| variable | tipo          | palabra   | significado |
| -------- | ------------- | --------- | ----------- |
| `int`    | número entero | integer   | entero      |
| `char`   | solo 1 letra  | character | carácter    |
| `bool`   | verdadero o falso | boolean | buleano   | 
| `float`  | valor decimal de baja fidelidad | float | flotante |
